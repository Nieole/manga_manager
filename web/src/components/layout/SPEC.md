## 职责与边界

本规格约束侧栏资料库三点入口的操作浮层。`LibraryActionsPopover` 负责按钮锚定、视口避让与临时交互状态；`Layout` 保有资料库目标、管理员可见性和既有操作回调。展示方式不改变扫描、编辑、迁移保护或删除确认流程，也不承担资料库数据管理。

## 可达性

浮层挂载在文档根部，避免被侧栏滚动容器裁切。根据按钮位置和实际内容高度选择展开方向：下方足够时向下，否则优先向上；两侧均不足时选择空间更多的一侧并限制高度，使全部操作可通过菜单内部滚动访问。水平和垂直保留视口边距，较长的翻译和迁移保护提示同样受此约束。

列表滚动、窗口尺寸或菜单内容变化时重新定位。入口完全离开视口，或被任意 overflow 裁切祖先完全遮住时关闭菜单；入口仍部分可见时保留锚定。菜单自身滚动不关闭浮层，滚动到边缘不向侧栏传递滚动。

## 键盘与关闭

打开后聚焦首个可用操作而不滚动列表。点击菜单外部关闭浮层；Escape 关闭并将焦点交回三点入口。浮层中的点击不触发底层资料库导航，三点入口具有可辨别的资料库名称和键盘焦点状态。
