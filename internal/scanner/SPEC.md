## 责任与契约

将资料库目录中的归档摄取为系列和书，决定扫描深度、增量跳过、改名身份重连、内嵌元数据导入与被触及系列统计。扫描不是把现有书删除重建；相同文件的身份重连由扫描策略决定。

清理删除文件已经消失的记录与无人引用的缩略图。watcher 去抖后只经装配注入的出口发起扫描或清理；本包维护正在扫描的库以避免不合时宜的 watcher 清理，但不自建第二个任务准入闸门。

扫描观察者只报告扫描本身；异步封面经独立封面运行和其句柄上报。封面批在真正执行时认领，不能在排队发起时先取走批次，否则合并声明后批次会丢失。

## 边界

解析、图像编码和指纹是支撑能力；外部抓取候选、提案裁决和外部目录会话不属于摄取。只消费执行资格与观察出口，不决定任务身份、重启和全局槽位。`doc.go` 中 API 持有编排与裁决的旧归属不作为现行约束，实际归属见 `mm-architecture`。

核对入口：`Scanner`、`ScanProfile`、`CoverBatch`、`FileWatcher` 与扫描增量、改名和封面测试。
