# 资料库路径迁移按根目录映射保留身份，异常记录受持久化保护

状态：已实施。`relocation.Service` 维护路径映射、补偿与持久保护，`application/relocating.Service` 维护排他访问及配置、监听和缓存的完整交接。

换机或盘符改变只改变漫画所在位置，不改变资料库、系列与书的身份。迁移按管理员确认的原根与目标根保持库内相对路径，原位更新路径并保留 ID；已有目标记录冲突时阻止，内部改名、目录重排与记录合并各有独立歧义，不由扫描或内容相似性猜测解决。

允许用户接受目标书文件缺失、不可读或大小不同，代价是这些记录可能暂时无法阅读，因此迁移同时建立可跨重启保留的异常保护，停用该库自动处理，并约束所有失踪清理入口。只关闭自动扫描无法保护记录：手动清理仍能级联删除阅读记录。保护仅由明确的管理员恢复操作解除，不能因迁移成功或后续一次扫描完成而自动清除。

数据库路径与配置文件中的目录 IO 策略必须作为一次用户操作保持一致；提交、补偿和启动恢复共同维护这个约束。独立的数据库事务和配置文件原子替换并不构成跨介质事务，失败恢复结束前该资料库保持不可访问。
