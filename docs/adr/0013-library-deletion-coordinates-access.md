# 资料库删除协调准入并保留失败结果

实施状态：统一任务引擎提供关闭准入的保留、真实占用查询及原子独占升级，完整资料库管理用例已接入空闲删除和占用冲突呈现。主动取消及有界等待由后续排空工单承接。

删除先关闭目标资料库的新工作准入，请求取消可取消的本库运行并有界等待。阅读访问、不可取消工作或跨库系统工作仍占用时，返回明确冲突而不删除记录；不得因为删除单库取消覆盖其他库的系统运行。准入与占用复用统一资料库访问协调能力，不另建仅删除入口知道的并发锁。

删除失败或放弃后释放准入并恢复符合当前设置的监听；已发生的运行取消如实表达，不自动重新执行可能写盘、清理或付费的工作。相较尽力取消后直接删行，接受短暂阻止访问与明确冲突的成本，避免将外键拒绝晚到回写作为主要协调机制；不承诺外部副作用随数据库事务回滚。
