# 提案进入终态后不能继续应用字段

实施状态：提案应用在 SQLite 写事务内重读待裁决状态、字段、系列当前值及锁定后选择本次写入。终态与部分应用竞争由真实事务屏障回归验证。

完整应用与部分应用都必须在写入事务中确认提案仍待裁决；并发裁决已使提案进入终态时，后来的应用返回冲突，元数据、提案字段及来源沿革均不提交。拒绝不撤销此前已成功应用的字段，部分应用成功后仍保留剩余待裁决字段。

事务外预检有利于快速拒绝冲突，却不能保证预检后提案仍待裁决。接受事务内守卫与并发回归的成本，使裁决状态和实际写入一致，避免出现被拒绝后仍继续写入及错误沿革关联。
