# 书内容发布协调活跃读取并保留原文件

实施状态：页清单、页图、封面页读取与整书句柄由 `bookcontent` 集中，直接打开、整书流与归档池借用共用活跃观察；整书句柄关闭前持有资料库读取资格，ComicInfo 发布协调待后续工单实施。

页读取、页清单与整书打开共享内容访问能力，集中管理来源、归档借还、加工、缓存资格及访问租约；身份与设备协议不因此并入内容总对象。整书下载在读取句柄关闭前持有必要访问资格，不因发布新归档强行截断已建立读取。

ComicInfo 临时归档构建尽量与读取并行，最终替换前取得该书短期写入资格，阻止新借用并有界等待原借用者退出；仍被占用或原文件已变化时明确失败，保留原文件。成功发布后由内容能力交接事实更新和缓存失效；文件系统替换行为须实际验证，不能将池淘汰等同使用者已经退出。

尽力替换实现简单，却把活跃句柄、平台文件共享语义及缓存一致性泄漏到调用者。接受短期写入协调与明确冲突的成本，复用资料库删除/迁移访问协调与任务准入的已有分工，不引入另一套任务准入锁。
