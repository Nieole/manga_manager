# 作品群派生更新允许滞后但必须可恢复

实施状态：待实施。本决定用于下一轮作品群派生更新设计。

关系写入可先于作品群重建完成，避免把整图重建放入每次关系写事务。必须持久保留尚未完成的更新依据，失败后自动重试、重启后继续恢复，并让查询区分当前、陈旧与失败结果；关系变更成功不能被表示为作品群也已更新完成。

已有成功结果继续可读，并标明更新中或更新失败及陈旧状态；首次没有成功结果时显示不可用，不把空集合解释为重建成功。提供立即重试，同时保留后台退避修复，不能因一次失败永久丢弃修复责任；只保存恢复和呈现所需依据及最近结果，不新增完整关系事件账本。

仅内存合并和记录错误实现简单，但无法保证失败或重启后最终修复。接受持久状态及恢复协调的成本，同时保留作品群稳定身份和事务内成员差集更新；具体机制另行设计，不据此引入全站消息总线。
