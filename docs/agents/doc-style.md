# 文档与注释

`AGENTS.md` 的 Documentation & Comments 一节是常驻判据，本文是那一节答不下的部分。动手前读与你要改的那部分相关的小节。

## 分层

每层只答一个问题。答不下的往下一层沉。

**Go**

| 层 | 位置 | 回答 | 预算 |
| --- | --- | --- | --- |
| 包 | `// Package xxx …`，由 `ST1000` 强制 | 这个包是什么、边界在哪 | 3–8 行 |
| 文件 | 文件顶部，与 `package` 之间空一行 | 本文件在包里占哪一块 | ≤5 行 |
| 符号 | 紧贴导出声明 | 契约：前置条件、并发要求、错误语义 | 一事一议 |
| 行内 | `//` | 为什么这么写 | 一两行 |

**前端**：同上，去掉包这一层。TS 的目录不是语言级的包，目录级说明没有任何工具会去读，写下来就开始腐坏——`web/src` 的结构由 `AGENTS.md` 回答。文件头写在所有 `import` 之前，符号 doc 紧贴声明；位置就是分层。

**测试文件**：文件头只答**这些测试在守哪条不变量、破了会怎样**。测试名已经答了测什么，断言已经答了怎么判。

## 归属

### 内容归哪个文件

按**读者**分；重叠时看谁会来读。

| 文件 | 读者 | 独占 |
| --- | --- | --- |
| `README.md` | 用户、部署者 | 是什么、能干什么、怎么装、怎么配 |
| `AGENTS.md` | 在仓库里干活的人和 agent | 结构、命令、风格、约定 |
| `CONTEXT.md` | 两者 | 只有词汇，没有实现 |
| `docs/adr/` | 要改架构的人 | 拦阻性决策 |
| `docs/agents/` | agent | 技能协作细节 |
| `CHANGELOG.md` | 用户 | 版本史 |
| `.scratch/` | 干活的人 | 在飞的工作（不进 git） |

环境本身也是一处归属。写进文档的应当是环境里查不到的东西：不成文的约定、某个选择背后的理由、配置文件不会承认的坑。`package.json` 的脚本名、`config.example.yaml` 的字段、`--help` 的输出一次查询就能拿到，留在环境里，那里不会过期。

### 历史归哪里

历史只属于 `CHANGELOG.md` 与 `docs/adr/`。碰到带历史的注释，按顺序判：

1. 剥掉历史后剩下的能写成一条**约束**（必须 / 不得 / 否则会…）→ 就地改写成约束，历史丢弃。
2. 写不成约束，但这段历史**拦得住一个看起来明显正确的改动** → 升 ADR，注释里留结论加引用。
3. 都不是 → 删。

## 不会腐坏的引用

引用代码写**符号名**，跨包写 `包名.符号名`：重命名时它跟着改，grep 找得到，IDE 跳得过去。文档里写路径。

随代码漂移的现状数字与位置会腐坏，而且腐坏时没有任何机制会报警：行号、出现次数、包或文件的行数、「上面那个函数」「见下方」。

一次测量得到的结论不是现状快照——「实测 UNION 形态比 instr 全表扫快一倍」带时间戳语义，别人改代码改不坏它。这类结论写进 ADR。

## 一个完整的例子

下面这 13 行文件头把三种内容混在了一起（取自 `internal/api/task_engine.go` 改写前）：

```go
// 本文件是后台任务引擎，持有任务子域的**全部可变状态**并独占其锁。
//
// 此前这些状态挂在 taskEngine 上、方法却挂在 Controller 上（`c.taskEngine.xxx` 出现 130+ 次），
// 于是「谁能改任务表」这条边界在 17.9k 行的 api 包里没有任何结构约束……
//
// 并发约定：
//   - 除 relaunchers 外，全部字段由 mutex 保护。
//   - 名字带 Locked 后缀的方法要求调用方已持锁。
//   - 任何要把 TaskStatus 带出临界区的路径必须先 cloneTaskStatus，否则……
```

三段各有去处：

- 第一段答的是「本文件占哪一块」，**留在文件头**。
- 并发约定是类型契约，**沉到 `taskEngine` 的符号 doc**。
- 中间那段剥掉历史后，残值是一条约束——「Controller 不得直接触碰任务表」。写成约束之后历史丢弃，`130+ 次` 与 `17.9k 行` 随之消失。

文件头剩两行：

```go
// 后台任务引擎。任务子域的全部可变状态归它所有，只依赖三样外部能力：落盘的 store、
// 投递 SSE 的 publish、感知停机的 done。Controller 不得直接触碰任务表。
```

## 检查器

`scripts/check-doc-style.sh`，CI 在 ubuntu 上跑，本地可手动跑：

- **拦截**：文件头超预算；行号与现状统计数字。
- **提示**：疑似历史叙述的词（原来 / 之前 / 不再 / 旧的）。这一项误报多——「距 t 若干天之前」是业务语义不是历史——所以只打印不拦截，由你按上面的三段判定逐条处置。

包注释的存在性由 `.golangci.yml` 的 `ST1000` 强制，不在脚本里重复检查。
