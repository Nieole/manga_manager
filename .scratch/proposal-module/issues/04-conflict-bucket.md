# 04 — 批量结果新增 conflict 桶

**What to build:** 批量应用或批量拒绝时，那些「已经被别人处理过」的**提案**单独成桶，不再混进失败里。今天用户会为一堆并没有坏掉的东西看到红色的「失败 N 项」——最常见的情形就是另一个标签页、另一个人或上一次操作已经处理过它们。

这是本批次唯一一张改前端契约的票。
