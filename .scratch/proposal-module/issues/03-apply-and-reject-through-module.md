# 03 — 应用与拒绝走模块（写入器迁入）

**What to build:** 应用或拒绝一条**提案**——无论从单条入口还是批量入口——都走同一条通路。调用方交出提案 id 与模式，拿回一个已经分类好的结局；「读提案 / 判 pending / 读字段行 / 按 mode 筛 / 读系列 / 裁决 / 解释错误」这五步不再在两个 handler 里各抄一遍，两处也不可能再对同一种结局给出不同的分类。

元数据写入器一并迁入模块：「写元数据」与「关单」在模块内是同一次事务的两段，那条把事务句柄递出去的 hook 参数随之消失。
