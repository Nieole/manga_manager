# 05 — 读路径与计数走模块

**What to build:** 读**提案**的三条路径——按系列列出、收件箱分页、审核中心角标的待裁决计数——全部经模块。读路径留在 api 就意味着它们仍握着全量存储接口，票 01 修掉的那个 N+1 仍然写得出来；搬进模块并只暴露批量版之后，它在编译期就消失了。

「锁定状态按**当前**值算」这条规则一并迁入模块：它是一条裁决规则，不是渲染细节。今天它藏在视图映射的一个 `||` 里，而它防的是「先入队、后加锁」的字段没有锁徽章、用户点了应用却被静默丢弃。

**Blocked by:** 01, 02

**Status:** done

- [x] 视图映射里合并锁定状态的那个 `||` 消失，映射只剩字段搬运
