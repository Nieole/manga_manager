# 06: 书签与时长的完整命令

**What to build:** 书签与时长通过主体明确的功能接口处理，调用者无需知道存储形状或兼容统计步骤。

**Blocked by:** 01: 单书读者视图与导航。

**Status:** ready-for-agent

**规格覆盖：** [父规格](../spec.md) US 24、30、31、39、43。全部验收同时遵守父规格的兼容、测试及范围外约束，不重新定义已批准业务规则。

**切片类型：** 纵向切片。

- [ ] 书签主体、书范围、页码约束及无阅读副作用保持，时长活跃性及上限保持。
- [ ] 只收窄实际使用的数据能力，不把软统计改为事件账本或盲目重试。
- [ ] 前端阅读器和 HTTP 实际消费完整接口，切书/身份变化不串写。
- [ ] SQLite 和消费者回归验证，不为已清晰技术辅助额外造领域层。
