# 37: 重启声明与有损合并事件

**What to build:** 完整落地输入/标签分离，让每次有损合并可追查，重启按行为输入执行。

**Blocked by:** None (can start immediately)。

**Status:** ready-for-agent

**规格覆盖：** [父规格](../spec.md) US 156、157、158、159、160、161、164。全部验收同时遵守父规格的兼容、测试及范围外约束，不重新定义已批准业务规则。

**切片类型：** 纵向切片。

- [ ] 逐启动点区分重启输入、环境标签、上限、指标和文案参数，保持行为恢复。
- [ ] 每次不同重启入参合并记事件，无损仍首次降噪，不改变先排运行执行选择。
- [ ] 发起方不夹带行为，任务身份、槽位、IO 限额及上下文日志保持。
- [ ] 任务内存/落盘、真实启动/恢复和观测消费者验证全部迁移，不留两套声明规则。
