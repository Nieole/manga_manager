# 20: 复制中的取消与提交结果

**What to build:** 外部传输在复制块间响应取消，丢弃未提交暂存并保留已完成文件。

**Blocked by:** None (can start immediately)。

**Status:** ready-for-agent

**规格覆盖：** [父规格](../spec.md) US 108、109、110、111、112、113、118、119、120、121。全部验收同时遵守父规格的兼容、测试及范围外约束，不重新定义已批准业务规则。

**切片类型：** 纵向切片。

- [ ] 完整复制会话持暂存、目标、进度和提交结果；取消停止后续文件。
- [ ] 已有目标及复制期间出现的目标不覆盖，未提交暂存不计成功且被清理。
- [ ] 部分成功范围、会话刷新及运行状态正确，阻塞单次 IO 限制如实表达。
- [ ] 真实文件与可控 IO 屏障验证取消、目标竞争和失败；API/消费者结果可见。
