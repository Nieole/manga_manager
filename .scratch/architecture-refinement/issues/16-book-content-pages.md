# 16: 页读取的共享内容能力

**What to build:** 页清单与实际页读取集中来源、加工、缓存和归档借用，阅读器及封面等真实消费者接入。

**Blocked by:** None (can start immediately)。

**Status:** ready-for-agent

**规格覆盖：** [父规格](../spec.md) US 90、91、92、94、95、96、97、102。全部验收同时遵守父规格的兼容、测试及范围外约束，不重新定义已批准业务规则。

**切片类型：** 纵向切片。

- [ ] 完整内容 interface 隐藏来源定位、池借还与加工缓存资格，HTTP 只映射请求响应。
- [ ] 共享借用 seam 能识别旧消费者的活跃借用，为后续发布协调提供真实依据。
- [ ] 透传、实际加工、尺寸/解压/内存保护和来源变更缓存键保持。
- [ ] 真实归档、HTTP 与读取消费者验证；独立字节结果及时归还借用。
