# 05: 阅读位置与标记的窄事务

**What to build:** 在线、离线及批量标记经完整用例维护位置和读态，事务只暴露所需一致性能力。

**Blocked by:** 01: 单书读者视图与导航。

**Status:** ready-for-agent

**规格覆盖：** [父规格](../spec.md) US 25、26、31、32、39、41、42、43、44。全部验收同时遵守父规格的兼容、测试及范围外约束，不重新定义已批准业务规则。

**切片类型：** 纵向切片。

- [ ] 事务回调不能取得全量 sqlc 查询或任意 DB，实际适配不形成反向包循环。
- [ ] 原时间、事实身份、同页新阅读、回退、清除跨重启及批内聚合全部保持。
- [ ] 部分提交范围与缓存失效准确，统计告警不否定已保存位置。
- [ ] 真实 SQLite、并发和 HTTP/离线矩阵验证，退出对应无生产用途的绕过入口。
