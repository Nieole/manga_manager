# 17: 整书下载与读取句柄

**What to build:** HTTP 与协议下载通过内容句柄打开整书，在流结束前保留访问资格并正确归还。

**Blocked by:** 16: 页读取的共享内容能力。

**Status:** ready-for-agent

**规格覆盖：** [父规格](../spec.md) US 90、93、102、199。全部验收同时遵守父规格的兼容、测试及范围外约束，不重新定义已批准业务规则。

**切片类型：** 纵向切片。

- [ ] 下载与协议实际使用共享来源和句柄，所有完成/断连/异常路径归还资格。
- [ ] 迁移、删除和后续发布能观察真实活跃读取，不强制截断既有下载。
- [ ] Range、响应头、鉴权及公开下载行为保持传输适配职责。
- [ ] 真实文件流和协议回归验证资源归还及长读取冲突。
