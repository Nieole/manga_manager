# 30: 配置发布与生效范围

**What to build:** API 保存和文件重载共享发布能力，设置明确即时、后续作业或重启后生效。

**Blocked by:** None (can start immediately)。

**Status:** ready-for-agent

**规格覆盖：** [父规格](../spec.md) US 137、138、139、142、143。全部验收同时遵守父规格的兼容、测试及范围外约束，不重新定义已批准业务规则。

**切片类型：** 纵向切片。

- [ ] Manager 为事实源，版本冲突、密钥占位、校验及不同补偿政策保持。
- [ ] 逐字段说明生效范围，操作目标/来源/写意图在适当发起边界固定。
- [ ] 保存结果与实际生效状态可区分，设置页面消费明确结果。
- [ ] 配置持久化、重载、并发和 UI 回归验证，不将所有设置假装立即生效。
