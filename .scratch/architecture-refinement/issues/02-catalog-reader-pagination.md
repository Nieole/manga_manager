# 02: 系列列表的主体筛选与分页

**What to build:** 系列列表、搜索与详情读态使用明确读者视图，SQL 在分页前完成主体筛选、排序和计数。

**Blocked by:** 01: 单书读者视图与导航。

**Status:** ready-for-agent

**规格覆盖：** [父规格](../spec.md) US 21、22、23、28、29、40、174。全部验收同时遵守父规格的兼容、测试及范围外约束，不重新定义已批准业务规则。

**切片类型：** 纵向切片。

- [ ] 主体进入 SQL 筛选、排序、计数及分页，保留游标/偏移既有回退。
- [ ] 列表与详情按各自查询用途建模，批量读取和缓存不退化为逐项装载。
- [ ] 真实用户数据验证跨用户计数、页边界和未知页数，前端保持筛选与局部状态。
- [ ] 公开形状兼容，旧查询形式仅为未迁消费者暂留。
