# 36: 任务观测功能与传输契约归属

**What to build:** 任务中心和气泡消费功能自有投影，HTTP/SSE 契约及转换有明确传输归属。

**Blocked by:** None (can start immediately)。

**Status:** ready-for-agent

**规格覆盖：** [父规格](../spec.md) US 155、162、163、179。全部验收同时遵守父规格的兼容、测试及范围外约束，不重新定义已批准业务规则。

**切片类型：** 纵向切片。

- [ ] 任务观测不反向导入具体 TaskCenter/气泡组件的类型，组件消费功能接口。
- [ ] 运行 HTTP/SSE DTO 与转换从混合总装归位，领域不吸收公开 JSON 模型。
- [ ] 公开名称/字段、生成 TS、权限、重连及后端实况权威保持。
- [ ] 后端契约与前端任务消费者回归验证；移动类型的收益按依赖清晰度报告。
