# 01: 单书读者视图与导航

**What to build:** 新增明确主体的书事实/阅读视图，并让单书详情、上下本与阅读器实际消费新入口，保留公开响应。

**Blocked by:** None (can start immediately)。

**Status:** ready-for-agent

**规格覆盖：** [父规格](../spec.md) US 15、16、17、18、19、20、23、24、25、26、27、28、29、30。全部验收同时遵守父规格的兼容、测试及范围外约束，不重新定义已批准业务规则。

**切片类型：** 纵向切片。

- [ ] 藏书事实与读者状态可区分，非法主体不降为匿名，用户与匿名兼容路径隔离。
- [ ] 详情、上下本与阅读器使用完整查询入口，公开字段兼容，未知完成及有效回退保持。
- [ ] 新增形式旁保留仍有消费者的旧形式；新形式至少有一条生产链使用，后续迁移不破坏编译。
- [ ] 真实 SQLite、HTTP 和阅读器消费者验证，不以新增无人调用类型作为完成。
