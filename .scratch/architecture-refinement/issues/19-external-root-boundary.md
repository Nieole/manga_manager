# 19: 外部库全资料库边界

**What to build:** 外部会话拒绝与任一资料库重叠的路径，页面明确解释冲突并由功能持有传输投影类型。

**Blocked by:** None (can start immediately)。

**Status:** ready-for-agent

**规格覆盖：** [父规格](../spec.md) US 106、107、108、109、179。全部验收同时遵守父规格的兼容、测试及范围外约束，不重新定义已批准业务规则。

**切片类型：** 纵向切片。

- [ ] 相等、祖先及后代重叠均对全部登记资料库检查，沿用平台路径语义。
- [ ] 保留访问协调与会话失效，旧计划不能绕过路径/保护变化。
- [ ] 外部功能拥有自身类型与完整会话契约，页面和组件消费，不反向定义接口。
- [ ] 真实临时路径、API 和外部库界面验证跨库、正常路径与失败分类。
