# 01 — 收紧归档打开的令牌持有区间

**What to build:** 扫描 worker 处理一本书时，**存储令牌**只覆盖真正的归档 IO——打开归档、读页目录、读 ComicInfo、关闭。今天被夹在持有区间里的那段纯 CPU 工作（把相对路径拆成系列名与卷名、算复合哈希、提取排序号、挑封面候选）挪到令牌归还之后。

用户侧可观察的变化：在慢盘上并发扫描时，归档打开的并发额度不再被 CPU 工作虚占，同一时刻真正在读盘的归档数更接近配置值。

这是一次预重构，行为等价。它同时是票 03 的风险前置：如果这段区间根本收不拢，在这里就暴露，代价只是一个扫描器内部的提交。

**Blocked by:** 无 — 可立即开始
