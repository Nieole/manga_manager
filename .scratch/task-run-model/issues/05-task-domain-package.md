# 05 — `internal/task` 领域包与落盘端口

**What to build:** 新建领域包，把**任务**与**运行**的模型、状态机、四条**终态**的裁决、运行槽位
与落盘端口立起来，并配一套纯内存的契约用例。**本票不接线**，对用户不可见——它是后面每一张票的
地基，也是 ADR 0006 拆两包的兑现点。

**Blocked by:** 无 —— 可立即开始

**Status:** ready-for-agent

## 边界（ADR 0006）

**这个包不知道 SQL。** 它定义落盘端口，`taskstore`（票 06）实现它。依赖方向是领域 → 端口 → 适配器，
不要反过来让端口长成表的形状。

不属于本包的东西：**任务键**怎么拼、i18n 文案码、HTTP 语义、**磁盘作业**的限流规则、
**暂停闸门**的实现。前三样属于 `api`，后两样属于 `diskwork` / `storageio` / `taskcontrol`。

## 状态机（形状来自本次盘问，比散文更精确，故内联）

```
排队中 ──→ 运行中 ──→ 完成 / 已取消 / 失败
  │          ↕
  │      已暂停 / 取消中
  └──→ 已取消（排队时被取消）

重启：活动态与排队中 ──→ 中断
```

**排队中**既不是**活动态**也不是**终态**：不占运行槽位，却仍会开跑。判 `taskIsActive` 的地方
必须逐处确认它该不该把排队中算进去——多数不该，但保留裁剪那处该（排队中永不被清）。

## 本票要立起来的

- 身份（类型、作用域、作用域 id、**变体**）与它的长期属性（禁用、上次成功、连败次数、退避到期）
- 运行（**发起方**、第几次、状态、阶段、计数、暂停累计、合并计数、时刻）
- 终态裁决：**任务体返回的错误**决定进哪一条，文案只能改文案。这条从既有引擎原样继承，
  不得再开「任务体自行调用收尾方法」的第二条路径。
- 运行槽位：单一全局数字，默认 2。上限的取值来源本票不接（配置在票 11 接线），先做成参数。
- 落盘端口：领域需要什么就声明什么，不要把表的全部列铺进去。

**队列、合并、退避、保留、事件、采样的规则本票不实现**，它们各有自己的票；但状态机要能容纳
排队中这个状态，端口要能容纳它们将来的写入，否则票 11 起会返工。

## 验收

- [ ] 新包不 import 任何 SQL/数据库包，落盘端口在本包定义
- [ ] 状态机覆盖排队中、活动三态与四条终态；排队中被取消进已取消
- [ ] 终态裁决只有一条路径，由任务体返回的错误决定
- [ ] 槽位放行按单一全局数字，超限的留在排队中
- [ ] 契约用例在纯内存下跑，不需要数据库、配置或扫描器；后台执行注入同步版，终态在调用返回时已落定
- [ ] 时钟可注入，节流与时序断言不靠 sleep
- [ ] `GOCACHE="$(pwd)/.gocache" GOTMPDIR="$(pwd)/.tmp" go test ./...` 全绿
- [ ] `go vet ./...`、`golangci-lint run` 无 issue、`gofmt -l` 干净、`check-doc-style.sh` 通过
