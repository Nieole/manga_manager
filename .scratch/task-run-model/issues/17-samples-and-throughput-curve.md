# 17 — 采样与吞吐曲线

**What to build:** 详情页画出这次运行的吞吐曲线，「它是不是卡住了」不用靠猜。每 10s 对计数与速率
取一个点。

**Blocked by:** 16

**Status:** done

## 采样只用来看趋势

**计数的事实来源是运行行本身，不是采样点。** 采样丢一个点没有后果，界面上曲线少一段而已；
不要让任何判断（进度、终态、速率显示）依赖采样表。

## 边界

- 采样只对**活动态**的运行取，排队中与终态不取。
- 采样保留 7 天（票 18 执行），比运行本身短：曲线是排障用的，一周之后运行还在、曲线没了，
  这是设计而不是缺陷，界面上要说清楚。
- 采样写入要节流成本可控：10s 一次、每条运行一行，不要跟着进度帧走。
