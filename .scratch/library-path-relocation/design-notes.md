# 资料库路径迁移设计记录

状态：产品设计已确认，尚未实施。本文保留 grill-with-docs 的问答结论与调查记录；正式规格已由 to-spec 生成于同目录 spec.md，后续拆票和验收以正式规格为准。

## 目标

资料库随移动硬盘换机或根目录改变后，保留已有系列与书的身份、阅读记录及元数据，恢复对原文件的访问。术语见根目录 CONTEXT.md 的「资料库路径迁移」。

## 已确定的边界

- 用户事先将文件放在目标位置，本功能只重新关联路径。
- 根目录下的相对路径保持一致；内部目录重排和文件改名不在本次范围。
- 目标路径已存在系列或书记录时，展示冲突并阻止迁移；保留双方数据，不自动合并。
- 每个资料库提供独立入口，流程为选择位置、检查预览、确认迁移、展示结果。已有系列或书的资料库在普通编辑中修改根路径时，引导进入此流程。每次操作一个资料库。
- 包含补迁移：资料库根已改变、系列与书仍持有旧路径时，展示推断的原根供用户核对或手动指定。原位置可不可达；映射必须能由一个原根完整解释现有记录。
- 检查新位置的书文件存在性与大小；缺失、不可读或大小不一致需要展示，但允许用户继续。迁移不做全量内容验证。
- 相关后台工作处于运行中或排队中时，列出冲突并阻止迁移，由用户先完成或取消。实际迁移期间短暂独占该资料库，阻止新的相关后台工作和文件读取；其他资料库在不冲突时保持可用。
- 所有原记录均映射到新根，包括存在异常的书。异常需明确确认；该资料库自动扫描、目录监听与失踪清理持续关闭，直到用户主动恢复。手动扫描或清理入口也必须提示异常。
- 原根及其子目录的 IO 策略随迁移映射，在预览中展示。目标存在不同策略时阻止；无关策略保持不变。
- 仅管理员可操作；检查与执行进入现有任务中心，检查阶段可取消，正式写入整体提交。结果包含系列、书、异常与处理结果，关闭弹窗后仍可查看。
- 迁移成功不主动发起扫描，由用户决定何时扫描。

## 操作流程

1. 管理员在资料库入口选择迁移，填写目标根目录。正常迁移使用当前根；补迁移展示旧根候选并允许明确指定，候选仅作提示。
2. 发起检查运行。展示原根、目标根、系列和书的映射数量与路径示例、IO 策略变更、阻断项和书文件异常明细。
3. 管理员确认预览；有书文件异常时额外明确接受异常与保护规则。阻断项必须解决后重新检查。
4. 发起迁移运行。提交前重新验证资料库数据、策略、路径冲突及相关工作状态；预览过期时要求重新检查，不能使用陈旧计划覆盖新数据。
5. 获得资料库独占访问后完成路径与策略的整体变更，更新监听并使依赖旧路径的缓存和外部库比较会话失效。
6. 任务中心保留迁移结果与异常清单。异常保护在服务重启后保持；恢复自动处理是明确的管理员操作，并展示尚存异常与清理后果。

## 阻断项与可接受异常

以下为阻断项，不因管理员接受书文件异常而绕过：

- 目标根不存在、不可访问或不是目录。
- 原根无法覆盖待迁移系列与书；路径越出根、映射不唯一或数据库记录混杂，无法按单根规则解释。
- 映射路径与现有系列或书记录冲突，包括其他资料库记录。
- 目标目录 IO 策略与迁入策略冲突，或策略迁移会改变其他资料库的既有配置语义。
- 有相关运行中或排队中的工作，包括作用于本库系列的工作、覆盖本库的系统维护、外部库传输。
- 计划过期、并发设置修改、无法取得独占访问或持久化失败。

可接受的书文件异常为缺失、不可读和大小不同，均展示原记录与目标路径并计数。只做文件信息检查，不据此声称内容相同。系列可为根目录散装书的虚拟系列，不要求系列路径在磁盘上是一个真实目录。

## 数据与一致性约束

- 保持 library、series 和 book 的 ID；元数据、字段锁、阅读进度、书签、合集、提案、来源与阅读活动等关联保留。路径按目录边界映射，避免裸字符串替换。
- 漫画文件内容、内容指纹、库内相对路径指纹及封面缓存路径保留，不把漫画根目录替换进缓存路径。
- 异常保护必须持久化；仅把 scan_mode 设为 none 不足以拦截手动清理。保护覆盖缺失书删除和缺失系列删除，API 与扫描服务均不能绕过约束。
- 迁移期间的访问约束覆盖后台任务的准入和放行、在途文件访问、监听排期与外部库传输计划。已有不可取消的清理必须先结束；不把取消请求当成退出证明。
- 预览与迁移均复用现有任务、运行和磁盘作业语义；已有系列或书的普通根路径修改不能绕过迁移。空资料库可以继续普通编辑。
- 路径策略修改经 config.Manager 生效。数据库与配置文件之间须有明确的失败补偿和崩溃恢复，重启恢复完成前拦住受影响资料库访问，避免对外暴露半迁移状态；不把两个单独的原子写误称为整体原子操作。
- 提交前取消不改变原状态；提交阶段不承诺即时取消。重复提交同一计划不重复改写，也不能重放覆盖后续迁移。
- 成功后的缓存失效、监听更新与保护状态可恢复；附属更新失败不能伪装成路径未提交，也不能提前允许旧路径工作继续执行。

## 验收场景

- 原硬盘盘符改变，嵌套系列和根目录散装书迁移后 ID 与关联数据不变，读取使用新路径。
- 资料库根已改、子记录未改，可明确旧根完成补迁移；单系列场景不把共同前缀当作可靠历史。
- 目标已有记录或不同策略时给出冲突，所有路径与策略均不变化。
- 缺失、不可读、大小不同的书经确认仍迁移；异常记录在扫描、清理、重启后保持，自动处理不会擅自恢复。
- 检查期间取消、预览后新增书或修改设置、提交失败以及进程中断，均不会让陈旧计划或部分写入对外生效。
- 本库的运行中、排队中、系列级和跨库工作均正确阻断；不冲突资料库保持可用；旧外部库会话不能在迁移后传输到旧位置。
- 迁移过程中设置页并发保存与配置热重载不会覆盖路径策略，服务重启可恢复一致状态。
- 用户封面、KOReader 相对路径指纹与内容指纹保留；完成后不自动发起重扫。

## 已核实的实现约束

- Controller.updateLibrary 仅更新资料库行；系列与书独立保存路径。
- 扫描按系列路径匹配，修改根路径后不能依赖重新扫描完整保留系列身份。
- 排队中的扫描已捕获原资料库路径；取消运行与移除目录监听均不能保证旧路径工作已退出。
- 根目录变化不改变 KOReader 的库内相对路径指纹；封面缓存路径独立于漫画根目录。
- 路径级存储策略属于 config.Manager 管理的配置；资料库路径事实来源为数据库。
- 后台磁盘工作与任务准入遵循 docs/adr/0005-every-disk-touching-work-gets-a-run.md。
