# 01: 统一资料库访问协调

**What to build:** 对现有资料库访问做行为保持的预重构，为迁移提供统一的独占与冲突观察入口。管理员以后检查或迁移时能够知道哪些工作仍持有资料库；进入独占后，旧路径工作不能混入，其他不冲突资料库继续使用。本票不开放迁移写入，也不新增独立任务引擎。

**Blocked by:** None (can start immediately).

**Status:** done

规格覆盖：用户故事 37、38、39、40；实施决策 12、13、18、23。

- [x] 既有扫描、清理、封面、系列级工作、覆盖资料库的系统级工作、定时与监听派发统一声明受影响资料库；保持任务领域对准入、排队和运行终态的唯一归属，不在 Scanner 再建一套同类准入。
- [x] 独占申请与冲突检查没有先检查后插入工作的竞态；活动态和排队中的相关运行均可识别，并返回运行标识、资料库关联及可操作原因，不以任务键寻址。
- [x] 已排队扫描持有旧资料库路径这一事实被覆盖：受阻期间不能放行旧闭包；本库取消中的运行、未退出的任务体仍视为冲突。
- [x] 不自动取消用户工作；不可取消清理必须结束后才能取得独占，取消请求不能作为退出证明。
- [x] 约束在途及新文件读取、监听排期、外部库比较、传输计划生成和传输启动；仅移除 watcher 或清除会话不算已独占。
- [x] 外部库已经生成但尚未启动的计划能被迁移失效约束覆盖，不能在取得独占后绕过启动检查；不会提前取消或破坏现有有效会话。
- [x] 暴露稳定的资料库访问占用与受阻语义供后续接口使用；未启用迁移独占时，现有 HTTP、阅读、协议和后台工作行为保持一致，不借机重写调度体系。
- [x] 独占可在成功、失败和提交前取消时可靠释放；受阻请求得到可识别的暂时不可用结果，不假报文件丢失。其他资料库和不冲突的工作可继续。
- [x] 使用已有 Controller、真实 SQLite 和可控后台执行，覆盖本库、系列、系统及跨库工作；用屏障验证独占与新任务、排队放行、读取、监听派发、传输启动之间的竞态，不依赖固定 sleep。
- [x] 通过既有接口验证行为保持；不为每个内部锁或 helper 设置测试接口。保持 ADR 0004—0008 的身份、运行、准入和控制语义。

本票是明确的前置接缝整理，验收是现有调用已接入且可验证独占规则，不是创建一把尚无调用方的锁。遵循父规格的实现门禁；本票不搬运漫画文件、不修改资料库路径。


## Comments

2026-10-20 实现与验证：

- `task.Engine` 的 `LibraryConflicts`、`AcquireLibraryExclusiveForRun`、`AcquireLibraryRead` 与运行准入共用同一边界；资料库关联保留到任务体真正返回，排队闭包也构成占用。当前运行通过 ctx 的运行标识排除自己，不新增任务键寻址或 Scanner 准入。
- Controller 装配统一声明资料库、系列及覆盖所有资料库的系统工作；定时、监听、清理和封面沿用原启动入口。读取、下载、Mihon、同步 ComicInfo 写入、移除书、打开目录及资料库编辑/删除均持有访问租约并在租约内使用路径。封面错误兜底也不能越过独占。
- 外部库比较及规划持有访问租约，传输启动在准入边界重新验证会话；`external.Manager.InvalidateLibrary` 供迁移提交在释放独占前清除旧会话与待用计划。库扫描重新检查捕获的根路径，旧路径声明不会在独占后复活。
- 真实 SQLite 的 Controller 测试见 `internal/api/library_access_test.go`：活动态/取消中与排队占用、系列及系统覆盖、不可取消清理、在途下载屏障、新运行与独占竞争、监听/定时/封面派发、其他资料库可用、当前迁移运行排除自身、失败释放、旧传输计划与旧扫描路径拒绝。保留既有页来源缓存行为。
- 验证通过：`go test ./internal/api ./internal/task ./internal/external`；新增并发场景 `go test -race ./internal/api -run 'TestLibraryExclusive|TestLibraryRelocation|TestRelocationInvalidates|TestExclusiveBlocks|TestOldScanSnapshot' -count=1`；`gofmt -l ./cmd ./internal` 无输出；Go 1.26.5 下 `golangci-lint run ./internal/api/... ./internal/task/... ./internal/external/...` 为 `0 issues.`。
- 本票不提供迁移端点；后续提交必须在独占期间完成路径缓存刷新与 `InvalidateLibrary`，并用 defer 释放租约。整批前后端门禁由集成分支执行。
