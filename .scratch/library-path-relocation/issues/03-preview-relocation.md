# 03: 检查并预览资料库路径迁移

**What to build:** 管理员从资料库入口选择目标目录，发起只读检查，在弹窗和任务中心查看路径映射、相关工作、文件异常、记录冲突与目录策略影响，检查期间可取消，关闭弹窗后仍能查看结果。本票不提供真正改写路径的确认入口。

**Blocked by:** 01 — 统一资料库访问协调。

**Status:** ready-for-agent

规格覆盖：用户故事 2、3、6、10、11、12、21、22、23、24、25、26、35、37、38、41、42、43；实施决策 1、2、4—7、12、14、17、18、21、22。

- [ ] 资料库提供管理员专用“迁移路径”入口，复用目录选择、现有模态交互、i18n 与共享 API 客户端；展示当前原根、目标根及操作范围。
- [ ] 建立服务端可寻址的检查计划、检查运行及查询契约；计划包含资料库、原根、目标根、系列与书数量、映射示例、策略变更、阻断项和书文件异常分类。客户端不提交任意记录更新清单。
- [ ] 后台检查走现有任务中心、运行句柄和磁盘作业，展示阶段、计数与真实终态，日志使用带 ctx 的接口；取消检查不修改资料库、配置或文件。关闭弹窗不隐式取消运行。
- [ ] 计划与结果有持久化查询依据，不能只存在弹窗或临时内存；大结果分批读取，SSE 不反复携带完整记录清单，列表有界渲染。
- [ ] 按服务端原生绝对路径和目录边界映射，覆盖大小写、分隔符、尾分隔符、中文、空格及近似前缀；越界、无效根、无法解释的记录和真实目标占用列为阻断项。不得将所有嵌套资料库一概判为冲突。
- [ ] 目标已有系列、书或其他资料库记录时列出冲突，原数据不变；映射命中同一条原记录不能被误判成与他人冲突。
- [ ] 逐本读取目标文件信息，分类展示缺失、不可读、非普通书文件及大小不同；不解压或全量计算内容指纹，不把大小一致说成内容相同。虚拟系列无需真实目录。
- [ ] 预览原根及子目录显式 IO 策略的映射、目标不同策略冲突和对其他资料库的影响，祖先与无关策略保持不变；本票只计算和展示，不写配置。
- [ ] 通过 01 识别运行中、排队中、取消中、系列级、系统级工作及在途传输，显示为什么需先完成或取消；检查自身不得被误判为外部冲突，也不能用取消代替等待任务退出。
- [ ] 发起及含主机路径的计划、明细查询均执行管理员权限与 CSRF 约束；普通用户不能经任务载荷获得新路径泄露渠道。
- [ ] 主测试通过 Controller HTTP、真实 SQLite、临时目录与配置验证检查结果和无写入；前端验证选目录、取消、冲突、分页异常及关闭重开。断言行为而非内部 helper。
- [ ] 为后续确认保留计划事实与失效验证依据。尚未支持的提交分支明确不可执行，不把只读检查完成显示为迁移完成。

补迁移的旧根候选与明确指定交互归 05；本票不因原根不可靠而自动猜测。执行遵循父规格与 ADR 0009，包含所触及生成契约、前后端门禁和 UI 证据。
