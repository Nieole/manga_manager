# 01 — 跨库运行不再戴一块盘，IO 数不再报两遍

**What to build:** 用户看文件身份重建、低优先级哈希回填或任一 KOReader 任务的运行详情时，
不再看到一个存储档位与卷键——这四个任务**逐本走遍每一个资料库**，那个值来自它**最后一次真的读了盘**
的那本书所在的盘，配了按库策略的用户会照着它调错设置。同一批任务还把 IO 等待、暂停时长与哈希文件数
**同时**报进**指标**与运行参数，同一件事记了两遍，参数面板里因此堆着与指标面板重复的项。

这与上一批治好重建缩略图的是同一条判据（跨库的运行没有单一的盘可报），差别只在来源——那边是从没
观测过的全局默认，这边是真观测到的一次，**呈现上是同一个答非所问**。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 与盘无关的标签（执行模式一类）**保留**
- [ ] 同一份 IO 实况不再同时走两条通道：IO 等待、暂停时长、哈希文件数只进**指标**

- [ ] 在同一处断言：与盘无关的标签仍在
