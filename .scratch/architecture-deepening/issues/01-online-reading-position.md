# 01: 在线阅读位置的完整用例

**What to build:** 接通阅读状态 module、必要持久化及在线阅读入口，支持有效回退、拒旧、同页新阅读刷新与可识别重试。

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

**验收基准：** [父规格](../spec.md)。本票遵守其中的跨功能约束和范围，不将历史实现偏差重新定义成业务规则。

**规格覆盖：** US 2、US 3、US 5、US 6、US 8、US 10、US 12、US 13、US 15、US 18、US 19、US 20、US 26、US 27、US 28、US 45、US 46、US 48、US 108、US 110。

- [ ] 通过现有在线阅读入口实际调用独立阅读状态 module；建立本用例需要的窄依赖和最小持久化，不只新增无人调用的 interface。
- [ ] 按明确的用户与书处理位置；有效新报告允许前进或回退，较旧报告不能覆盖较新的阅读变更；新旧比较与写入在并发下仍成立。
- [ ] 有可信发生时间时按该时间比较和保存，没有时间的兼容输入使用服务端接收时间；保留时区归一化及现有响应兼容性。
- [ ] 同页发生较新的有效阅读时刷新最近阅读时间；前端保留可识别事实的稳定依据，重复发送同一事实不制造新阅读，不能仅以页码相同判定永久跳过。
- [ ] 保留合法页码、未知页数与无用户兼容路径；按用户隔离读取与写入，不回退到另一用户或全局遗留进度。
- [ ] 进度与派生系列聚合保持必要事务一致性；缓存失效与活动后续动作由完整用例接管，不向 HTTP 返回步骤配方。
- [ ] 准确区分状态写入失败和活动统计告警；进度已提交时不声称未保存，需要的兼容统计独立尝试且告警可观察。
- [ ] 新持久化可升级已有数据库，不重建书、系列、用户身份，不猜测补造旧事件；为后续清除依据和可识别重试留出本功能内部的扩展位置。
- [ ] 通过完整用例和真实临时 SQLite 验证回退、拒旧、同页新时间、可识别重复、用户隔离、并发、聚合回滚及统计失败；保留在线入口回归。
- [ ] 删除本用例被替代的旧规则；完成对应后端门禁、涉及前端的测试构建和必要生成检查，记录实际验证结果。
