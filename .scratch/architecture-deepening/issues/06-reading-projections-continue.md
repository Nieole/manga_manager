# 06: 共享阅读状态查询与继续阅读

**What to build:** 列表、详情、继续阅读和读取协议复用每用户读态判断，未知页数与已读状态解释一致。

**Blocked by:** 01: 在线阅读位置的完整用例；03: 批量读态与持久化未读保护；04: 批量已读活动与未知页数统计

**Status:** ready-for-agent

**验收基准：** [父规格](../spec.md)。本票遵守其中的跨功能约束和范围，不将历史实现偏差重新定义成业务规则。

**规格覆盖：** US 26、US 28、US 34、US 51、US 52。

- [ ] 系列列表、书列表、详情及继续阅读实际使用阅读状态的共享主体投影与读态判定；调用方不再各自重建相同规则。
- [ ] 用户无本人记录时不继承其他用户或旧全局进度；无用户兼容路径保留明确行为，读取不修改阅读时间或生成活动。
- [ ] 有效回退、同页新时间、已读标记、未读清除及未知页数在各视图含义一致，内部哨兵不被当成真实页数。
- [ ] 保留书的阅读顺序、上一书和下一书关系，以及全部已读或缺少可继续位置时的既有回退结果。
- [ ] 读取协议继续使用已有身份、分页与响应形状；只迁移共同阅读判定，不重写归档、图片或协议目录。
- [ ] 通过功能 interface 和真实 SQLite 对照同一主体在列表、详情、继续阅读及相关协议的可见结果，覆盖无记录、回退、清除、未知页数与跨用户。
- [ ] 移除重复投影和继续阅读判定；规则测试不要求初始化完整 Controller，保留相关 HTTP、协议和页面回归并完成门禁。
