# 03: 批量读态与持久化未读保护

**What to build:** 按书和系列标记读态；分批提交、记录清除依据，重启后旧记录不能复活已清除的位置，部分失败仍刷新已提交结果。

**Blocked by:** 01: 在线阅读位置的完整用例

**Status:** ready-for-agent

**验收基准：** [父规格](../spec.md)。本票遵守其中的跨功能约束和范围，不将历史实现偏差重新定义成业务规则。

**规格覆盖：** US 15、US 22、US 23、US 24、US 25、US 31、US 32、US 41、US 42、US 43、US 44。

- [ ] 按书与按系列的已读、未读入口接入阅读状态的完整用例；系列展开、数量限制与主体隔离由该功能处理，HTTP 不逐书拼装写入。
- [ ] 标记未读清除展示读态，同时持久保存最近变更及清除依据；不借用最近阅读时间，不新增活动，不删除过去活动。
- [ ] 旧补传和旧记录重放不能覆盖清除，服务重启后仍然有效；比清除更新的有效阅读可建立新位置，不形成永久封锁。
- [ ] 新前端批量操作保留原操作依据和发生时间，重试沿用同一操作；兼容旧输入但不为缺少证据的载荷承诺可靠判重。
- [ ] 保留分批提交及批内进度、变更依据和系列聚合的一致性；后批失败不能回滚或隐藏前批提交，不形成一个覆盖全部书的大事务。
- [ ] 失败结果仍让功能知晓已提交范围，相应缓存失效由提交事实触发；兼容入口的返回与可观察结果不得谎称全部未生效。
- [ ] 持久化升级不改变既有用户、书、系列身份；无法证明的旧清除不反向猜测回填，无用户兼容路径也能拒绝有证据的旧重放。
- [ ] 使用真实 SQLite 和可控时间覆盖按书、按系列、清除后重放、重启后重放、新阅读恢复、批内失败及后批失败；保留界面批量操作回归。
- [ ] 本票交付批量读态和清除保护；批量已读活动与未知页数全链统计由 04 完成，不在此引入第二份活动规则。
- [ ] 删除本票替代的旧读态写入配方，完成相关后端、前端、存储升级和生成检查。
