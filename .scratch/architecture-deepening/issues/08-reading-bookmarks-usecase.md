# 08: 书签的完整用例

**What to build:** 书签增删查通过阅读状态执行，保留用户隔离、页码约束、已有身份及页面行为。

**Blocked by:** 01: 在线阅读位置的完整用例

**Status:** ready-for-agent

**验收基准：** [父规格](../spec.md)。本票遵守其中的跨功能约束和范围，不将历史实现偏差重新定义成业务规则。

**规格覆盖：** US 26、US 28、US 50、US 52。

- [ ] 通过阅读状态完整用例完成书签列表、新建更新和删除，HTTP 仅解析、提取主体和转换结果。
- [ ] 保留书签身份、备注处理、合法页码及未知页数约束，不因归属迁移重新创建已有书签。
- [ ] 书签的查询、更新和删除均按主体与书限定，不允许用另一用户的书签标识越权操作。
- [ ] 保留缺失书、缺失书签与存储失败的既有可观察结果，书签操作不刷新阅读位置或伪造阅读活动。
- [ ] 使用功能 interface、真实 SQLite 和既有 HTTP/页面先例验证完整 CRUD、跨用户隔离、边界页码和故障。
- [ ] 删除本用例旧规则，不迁移图片或离线字节管理；完成相关后端及受影响前端门禁。
