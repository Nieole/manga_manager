# 19: 扫描封面批与封面运行

**What to build:** 扫描入队到实际运行认领完整迁移，合并不丢批，发起不阻塞扫描，暂停、槽位及恢复回填有效。

**Blocked by:** 17: 应用运行入口与历史保留清理

**Status:** ready-for-agent

**验收基准：** [父规格](../spec.md)。本票遵守其中的跨功能约束和范围，不将历史实现偏差重新定义成业务规则。

**规格覆盖：** US 90、US 91、US 101、US 102、US 103、US 106。

- [ ] 扫描排出的封面批交接、封面运行发起、开跑认领与完成等待由应用编排完整接管，扫描回调实际接入。
- [ ] 批按资料库排队并在实际运行开跑时认领，不能在发起时绑定到可能被合并掉的运行；多批合并不丢待处理封面。
- [ ] 封面发起不阻塞扫描入库，扫描与封面继续各自拥有运行、进度、指标和上下文。
- [ ] 运行槽位、暂停闸门、取消及后台磁盘许可继续控制实际封面工作，未获准运行时不能先生成。
- [ ] 重启重试或恢复按既有缺封面回填规则重新找工作，不依赖已丢失的进程内批；等待只针对正确的批和运行。
- [ ] 沿用唯一运行引擎，不新增扫描守卫或另外一套封面运行事实源，也不将扫描与封面合成一条运行。
- [ ] 应用与扫描集成测试覆盖槽位占满、发起合并、多批交错、暂停取消、等待和重启回填；完成相关后端门禁。
- [ ] 删除本票旧批次配对与发起副本，保留尚未迁移调用方的薄兼容入口。
