# 05: KOReader 新报告与旧记录重放

**What to build:** 匹配后接入共同当前位置规则；新报告允许回退，对账用原时间，清除保护跨重启，协议记录与位置失败准确区分。

**Blocked by:** 01: 在线阅读位置的完整用例；03: 批量读态与持久化未读保护

**Status:** ready-for-agent

**验收基准：** [父规格](../spec.md)。本票遵守其中的跨功能约束和范围，不将历史实现偏差重新定义成业务规则。

**规格覆盖：** US 14、US 18、US 21、US 22、US 23、US 24、US 26、US 47。

- [ ] KOReader 在完成账号认证、用户归属与指纹匹配后调用共同阅读位置用例；设备协议记录、匹配规则及规范记录仍由 KOReader 持有。
- [ ] 设备的新有效报告允许回退书当前位置，与 Web 同一主体同一本书的当前位置含义一致；同页新报告按共同规则处理。
- [ ] 设备协议没有客户端时间的新推送按接收时间处理；读取、对账、匹配校准及恢复投影使用原记录时间，不把执行时刻当成新阅读。
- [ ] 已标未读的旧设备记录不能通过重放复活书位置，且保护跨重启；更新的新设备报告仍可写入。
- [ ] 保留百分比夹取、页码换算和未知页数的既有合理处理，不凭设备百分比编造书页数；用户不互串。
- [ ] 书位置投影、活动告警、设备规范记录保存和设备响应准确区分；位置真正失败仍有诊断，统计失败不冒充进度未落库，不将这些动作硬合成跨功能大事务。
- [ ] 通过完整 KOReader 输入及真实 SQLite 验证匹配书的回退、新旧时间、清除后重放、重启、同页报告和独立故障；不能只测未匹配的设备规范记录。
- [ ] 删除旧的最远页投影分叉，保留协议兼容和必要端点回归，完成相关后端与生成检查。
