# 05: KOReader 新报告与旧记录重放

**What to build:** 匹配后接入共同当前位置规则；新报告允许回退，对账用原时间，清除保护跨重启，协议记录与位置失败准确区分。

**Blocked by:** 01: 在线阅读位置的完整用例；03: 批量读态与持久化未读保护

**Status:** done

**验收基准：** [父规格](../spec.md)。本票遵守其中的跨功能约束和范围，不将历史实现偏差重新定义成业务规则。

**规格覆盖：** US 14、US 18、US 21、US 22、US 23、US 24、US 26、US 47。

- [x] KOReader 在完成账号认证、用户归属与指纹匹配后调用共同阅读位置用例；设备协议记录、匹配规则及规范记录仍由 KOReader 持有。
- [x] 设备的新有效报告允许回退书当前位置，与 Web 同一主体同一本书的当前位置含义一致；同页新报告按共同规则处理。
- [x] 设备协议没有客户端时间的新推送按接收时间处理；读取、对账、匹配校准及恢复投影使用原记录时间，不把执行时刻当成新阅读。
- [x] 已标未读的旧设备记录不能通过重放复活书位置，且保护跨重启；更新的新设备报告仍可写入。
- [x] 保留百分比夹取、页码换算和未知页数的既有合理处理，不凭设备百分比编造书页数；用户不互串。
- [x] 书位置投影、活动告警、设备规范记录保存和设备响应准确区分；位置真正失败仍有诊断，统计失败不冒充进度未落库，不将这些动作硬合成跨功能大事务。
- [x] 通过完整 KOReader 输入及真实 SQLite 验证匹配书的回退、新旧时间、清除后重放、重启、同页报告和独立故障；不能只测未匹配的设备规范记录。
- [x] 删除旧的最远页投影分叉，保留协议兼容和必要端点回归，完成相关后端与生成检查。

## 实现与验证

- KOReader 保留认证、账号归属、字节身份、指纹匹配、百分比换页与设备规范记录；匹配书通过 `reading.RecordPosition` 写入当前位置，生产装配连接统计缓存失效。
- 新报告传递受信接收时刻 `ReceivedAt`；历史匹配与对账只传递 `OccurredAt`。两者互斥，由共同用例拒绝歧义输入，HTTP 请求不接受接收时刻。设备规范记录内部保存 `received_at_ns`（不输出 JSON），协议 `timestamp` 继续使用秒；旧库新增列保持零值并沿用已有 timestamp/created_at，不把匹配时刻或 updated_at 当成阅读事实。
- 位置错误、独立活动告警和设备规范记录保存错误分别表达；保留规范记录成功时设备协议成功响应，并将位置失败/活动软告警写入各自诊断状态。任务路径新日志使用带 ctx 的接口；没有引入跨模块大事务。
- TDD 红绿：匹配输入从 75% 回退至 25% 时，旧最远页规则留在第 24 页，改后为第 8 页；精确原时间重放回归暴露秒级时间截断；固定当地日末同一 tick 的新回退/同页报告先被当作历史重放拒绝，改后按接收事实顺序应用，同刻历史重放仍拒绝且活动日期不跨日。
- 真实 SQLite 覆盖用户/匿名 × pull/reconcile 的清除跨重启保护、新报告恢复、同页刷新、用户隔离、未知页数、旧库升级、账号归属查询失败、活动单边失败、规范记录保存失败。公共 HTTP 回归覆盖实际匹配书、vendor 响应字段/媒体类型、回退和已预热 dashboard 缓存失效；既有位置写入失败诊断与账号/端点回归保留。
