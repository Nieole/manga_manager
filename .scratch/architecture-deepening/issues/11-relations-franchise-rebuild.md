# 11: 系列关系与作品群重建

**What to build:** 从关系修改到作品群更新接通，保留稳定身份、成员差集、更新时间和人工只读。

**Blocked by:** 09: 人工合集的完整用例

**Status:** ready-for-agent

**验收基准：** [父规格](../spec.md)。本票遵守其中的跨功能约束和范围，不将历史实现偏差重新定义成业务规则。

**规格覆盖：** US 59、US 60、US 61、US 62、US 63、US 68、US 70。

- [ ] 系列关系创建、修改、删除到作品群重建完整接入藏书编排，用例拥有图关系、稳定身份与成员变化规则。
- [ ] 作品群仍由系列关系推导且人工只读；不将它转成普通人工合集，也不新增不必要后台运行。
- [ ] 按稳定自然身份更新作品群，身份未改变时保留合集标识；不整体删除再创建，保留 OPDS、Mihon 与站内引用。
- [ ] 按成员差集处理，保留未变化成员的加入时间；只有实际应变化的情况更新相关时间，无关合集保持稳定。
- [ ] 最后关系消失、连通分量合并拆分、空集合及已消失系列均按现有领域规则正确处理。
- [ ] 保留现有合并式重建调度与生命周期登记，必要能力注入不能让 module 反向依赖 Controller，也不能因只抽图算法留下事务配方。
- [ ] 以真实 SQLite 验证身份、成员、时间、人工拒绝、重建失败与协议访问，保留关系编辑页面回归。
- [ ] 删除旧关系和重建规则副本，完成对应门禁；后续只由唯一调度所有者接管生命周期。
