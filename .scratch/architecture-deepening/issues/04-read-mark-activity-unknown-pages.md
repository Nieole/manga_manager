# 04: 批量已读活动与未知页数统计

**What to build:** 所有批量已读路径计入原标记日活动，重试不造新日期；未知页数有活动但哨兵不进入真实页数聚合和展示。

**Blocked by:** 03: 批量读态与持久化未读保护

**Status:** ready-for-agent

**验收基准：** [父规格](../spec.md)。本票遵守其中的跨功能约束和范围，不将历史实现偏差重新定义成业务规则。

**规格覆盖：** US 29、US 30、US 33、US 34、US 36、US 37、US 39、US 40、US 45、US 46、US 48。

- [ ] 按书、按系列及所有主体兼容路径的批量标记已读统一生成阅读活动；新操作使用标记发生日期。
- [ ] 同一批量操作的重试沿用原日期；跨日恢复或后批重试不能把已提交部分记成另一天的新操作；标记未读仍不新增或撤销活动。
- [ ] 未知页数的已读状态仍能贡献活动日期和涉及书的统计，但不编造页数；内部哨兵不得进入本票写入、当前读态聚合和展示中的真实页数。
- [ ] 已读状态和页数未知分别表达，读态、系列聚合与展示使用一致解释；之后得到真实页数时不能把既有哨兵当作真实位置或阅读页数。
- [ ] 保留每日每书最大绝对页码的现有统计含义，不引入精确翻页增量或根据缺失证据重算旧活动。
- [ ] 活动写入按实际提交的书和批次执行；状态失败与统计告警分开，兼容统计独立尝试，不因一路失败无理由跳过另一路。
- [ ] 真实 SQLite 验证按书与系列、已读与未读、未知与已知页数、不同用户、重复及跨日重试、活动故障和部分提交；验证相关统计及界面不显示哨兵巨量页数。
- [ ] 删除被替代的活动分叉和页数解释副本，完成相关后端及受影响前端门禁和生成物检查。
