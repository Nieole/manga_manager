# 13: 有序阅读清单与进度回填

**What to build:** 清单编辑、排序、成员查询和当前用户进度回填拥有明确归属，维持有序语义及协议兼容。

**Blocked by:** 06: 共享阅读状态查询与继续阅读

**Status:** ready-for-agent

**验收基准：** [父规格](../spec.md)。本票遵守其中的跨功能约束和范围，不将历史实现偏差重新定义成业务规则。

**规格覆盖：** US 26、US 51、US 69、US 70。

- [ ] 有序阅读清单的创建编辑、成员增删、排序、查询及进度回填拥有明确功能归属，现有界面和协议实际接入。
- [ ] 保持成员顺序与重排行为，不套用无序合集成员规则，不因共享目录强制共用一个通用容器模型。
- [ ] 当前主体的书和系列进度由 06 的共同读取语义提供，回退、清除和未知页数在清单中保持一致。
- [ ] 保留清单和成员身份、缺失成员容错、权限、分页及现有协议响应，读取不产生阅读活动。
- [ ] 本票不以人工合集票为虚假阻塞，所需基础能力可在本功能内部建立，不能复制另一套阅读位置判定。
- [ ] 通过完整用例及真实 SQLite 验证重排、成员变更、用户隔离和进度回填，保留清单页面与协议回归。
- [ ] 移除被替代的顺序和进度规则副本，完成相关后端、前端及必要生成检查。
