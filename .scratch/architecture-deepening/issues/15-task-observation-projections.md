# 15: 任务实况、历史与气泡投影

**What to build:** 消费者接入统一会话，保留投递链补拉、轮询、终态气泡及后端实况权威，移除对应旧全局事件依赖。

**Blocked by:** 14: 应用会话连接与普通刷新

**Status:** ready-for-agent

**验收基准：** [父规格](../spec.md)。本票遵守其中的跨功能约束和范围，不将历史实现偏差重新定义成业务规则。

**规格覆盖：** US 73、US 74、US 79、US 80、US 81、US 82、US 85、US 89。

- [ ] 任务实况、任务历史和气泡从 14 的应用会话消费运行消息，各自持有自己的功能投影，不把全部页面数据塞进会话对象。
- [ ] 按投递链前序关系判断缺口，保留重连与漏帧后的补拉；正常节流的序号空档不能误判为丢帧。
- [ ] 全局槽位等实况汇总仍采用后端事实，不从局部运行快照列表重算；历史筛选和展开行为保持。
- [ ] 保留必要轮询、任务与运行身份区分、控制动作、终态气泡延时移除及管理员权限。
- [ ] 挂载、离开页面、切换身份与多消费者订阅不造成重复控制、重复请求或旧角色数据残留。
- [ ] 移除本票消费者对旧 DOM 自定义事件的直接依赖；兼容桥只服务尚未迁移消费者，不能复制两套投递链规则。
- [ ] 通过会话和消费者行为测试验证完整缺口恢复、重连、历史与气泡结果，保留任务页面及普通用户拒绝回归。
- [ ] 删除被替代投影与恢复副本，完成前端测试、构建和适用 lint，保持传输契约兼容。
