# 22: 外部库与 ComicInfo 磁盘用例发起

**What to build:** 扫描传输和回写的后台发起脱离请求处理，保留会话、访问覆盖、磁盘许可、取消及不可自动续跑约束。

**Blocked by:** 17: 应用运行入口与历史保留清理

**Status:** ready-for-agent

**验收基准：** [父规格](../spec.md)。本票遵守其中的跨功能约束和范围，不将历史实现偏差重新定义成业务规则。

**规格覆盖：** US 7、US 90、US 93、US 94、US 95、US 97、US 106。

- [ ] 外部库扫描、传输和 ComicInfo 回写的完整后台发起接入应用运行入口，真实 HTTP 输入继续得到兼容会话与运行结果。
- [ ] 外部库模块继续拥有传输会话与计划，回写继续使用已有归档及元数据能力；应用编排只承担完整协作，不吞并全部磁盘规则。
- [ ] 保留资料库访问覆盖、外部路径与资料库关系判断、旧路径闭包约束，与迁移独占仍共享同一协调。
- [ ] 保留磁盘许可、运行槽位、暂停取消、日志与进度归属，任务体不依赖请求对象或全局当前用户。
- [ ] 改变磁盘内容的工作保持原有重试/续跑能力，不新增自动续跑或凭空重建不持久的会话计划。
- [ ] 结束、失败、取消和传输后扫描刷新仍有唯一所有者，不能由 HTTP 在发起后自行拼接多个可能丢失的步骤。
- [ ] 通过应用用例及现有外部库、归档 fixture 验证扫描传输回写、排队、取消、迁移冲突与会话失效，保留相关页面回归。
- [ ] 删除被替代的启动配方，完成后端、相关前端及生成物门禁；过渡时与未迁移迁移编排共用访问事实源。
