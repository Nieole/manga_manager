# 21: 维护及 KOReader 校准运行发起

**What to build:** 索引、缩略图、身份哈希维护与对账校准迁入应用发起，重试和续跑按原声明执行，调用已迁移的扫描、封面与位置能力。

**Blocked by:** 05: KOReader 新报告与旧记录重放；18: 手动、定时与监听扫描清理；19: 扫描封面批与封面运行

**Status:** ready-for-agent

**验收基准：** [父规格](../spec.md)。本票遵守其中的跨功能约束和范围，不将历史实现偏差重新定义成业务规则。

**规格覆盖：** US 7、US 21、US 90、US 91、US 93、US 94、US 95、US 106。

- [ ] 索引、缩略图、文件身份和书指纹维护，以及 KOReader 对账与匹配校准的真实发起入口迁入应用编排。
- [ ] 索引维护调用 18 的扫描能力，缩略图及封面维护调用 19 的批/运行能力，KOReader 对账使用 05 的原时间重放规则。
- [ ] 保留任务类型、变体、作用域、发起方与原始重启入参；前台哈希重建和低优先级回填仍为允许并行的不同身份。
- [ ] 每种维护保持既有重试和可续跑取舍；不能把有明确限制的索引重建或其他任务无条件自动续跑。
- [ ] 保持磁盘作业、暂停取消、跨库汇总、保护状态与访问覆盖；任务体使用运行句柄和带上下文日志。
- [ ] HTTP 只发起或控制，启动 registry 登记真实应用用例，不复制具体循环或参数回退逻辑。
- [ ] 通过应用入口与重启场景验证原参数重放、跨库进度、缺封面回填、清除保护及旧进度不会复活。
- [ ] 删除对应旧启动配方与任务体对 Controller 的依赖，保持任务领域/落盘分工并完成相关门禁。
