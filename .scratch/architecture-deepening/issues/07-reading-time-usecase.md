# 07: 阅读时长的完整用例

**What to build:** 时长写入与活动归属移入阅读状态，保留活跃判断、可见性、切书结算和软统计失败语义。

**Blocked by:** 01: 在线阅读位置的完整用例

**Status:** ready-for-agent

**验收基准：** [父规格](../spec.md)。本票遵守其中的跨功能约束和范围，不将历史实现偏差重新定义成业务规则。

**规格覆盖：** US 26、US 45、US 46、US 49、US 52。

- [ ] 现有阅读时长上报接入阅读状态完整用例，主体、书、累加及活动写入有明确归属；不只移动一个存储调用。
- [ ] 保留前端活跃输入、页面可见性、空闲停止、心跳及切书结算语义，不将隐藏或空闲时间算入阅读。
- [ ] 保留时长为尽力而为软统计的处理，发送成功但响应丢失时不因盲目重试重复累计；旧书异步失败不能污染新书。
- [ ] 保留非法或非正秒数、单次上限、缺失书及兼容主体的合理结果，不增加没有事实依据的离线时长或跨日分摊。
- [ ] 时长与所需活动聚合保持既有必要事务关系；存储失败可观察，且不与已成功的阅读位置保存混淆。
- [ ] 用完整功能及真实 SQLite 验证用户隔离、累加、故障和聚合，前端验证可见性、切书、卸载与失败不重复；保留既有上报兼容。
- [ ] 删除相应请求处理中的规则副本，完成相关后端与前端测试、构建和生成检查。
