# 20: 资料库迁移与保护恢复编排

**What to build:** 源目标独占与相交保护、路径配置、缓存、外部会话、监听切换及失败恢复作为完整协作链接管。

**Blocked by:** 18: 手动、定时与监听扫描清理

**Status:** ready-for-agent

**验收基准：** [父规格](../spec.md)。本票遵守其中的跨功能约束和范围，不将历史实现偏差重新定义成业务规则。

**规格覆盖：** US 7、US 92、US 96、US 97、US 98、US 106、US 110。

- [ ] 迁移预检、提交及显式保护恢复通过应用侧完整协作入口执行，迁移 module 继续持有其确定性映射、持久事实及恢复规则。
- [ ] 保留资料库、系列、书与关联身份；只重新关联路径，不搬运文件、不重新导入、不猜测合并目标记录。
- [ ] 源目标资料库及目录相交资料库共同受访问排他和拓扑约束；活动与排队工作、读请求及路径快照版本仍正确参与。
- [ ] 数据库路径与配置 IO 策略提交、补偿及启动恢复保持完整，未完成恢复前相关资料库不得开放访问。
- [ ] 阅读路径缓存清除、统计失效、外部会话失效和监听切换全部成功后才能完成并释放访问；失败继续受保护。
- [ ] 显式恢复仍需管理员确认，异常保护跨重启有效，自动扫描、手动清理和其他入口不能绕过。
- [ ] 使用已迁移扫描/监听能力，其他尚未迁移工作通过同一访问协调兼容，不制造另一套资料库锁。
- [ ] 以真实 SQLite、配置文件及可控文件系统故障验证提交、补偿、重启、相交目录、缓存重填和失败后不可访问，保留管理界面隐私与权限回归。
- [ ] 移除旧请求侧拓扑和后续动作配方，保留迁移领域规则；完成后端、受影响前端和生成物门禁。
