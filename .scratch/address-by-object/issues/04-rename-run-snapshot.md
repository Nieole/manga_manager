# 04 — 运行快照类型改名，连同 i18n 键与浏览器事件名

**What to build:** 读代码的人不再在同一个函数里看见两个 `RunStatus`——一个是交给前端的**运行**
快照结构体，一个是运行状态那个字符串枚举。快照结构体改名为 `RunSnapshot`，与 SSE 事件名对齐。

同一批把另外两处按旧概念取的名字扫掉：八条运行状态文案的 i18n 键仍写作**任务状态**（它描述的
是一次**运行**的状态），以及同一份载荷在 SSE 与浏览器自定义事件两跳里叫两个名字。

**这一条推翻 `task-run-model` 规格的关键决定 16**（那里逐字写的是 `RunStatus`）。理由：那条决定
当时没有预见到本包里会同时出现两个同名不同物的类型。改动理由写进提交信息。
