# 03 — 删掉任务键那一列与契约上那一格

**What to build:** **任务键**从寻址里彻底退出。载荷上不再有它，`runs` 表上不再有它，筛选器上
不再有它——它退回它真正擅长的地方：**每一行日志上给人读**（见 ADR 0007）。

用户这一侧不该有任何可见变化：搜索已在 01 换了口径，重试已在 02 换了寻址，健康报告那个读者
在上一批就已改读**运行标识**。剩下的只是把没有读者的东西撤掉。
