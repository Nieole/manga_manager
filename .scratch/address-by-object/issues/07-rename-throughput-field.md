# 07 — 采样那一格改名 throughput_per_minute

**What to build:** 吞吐曲线上的数与运行卡片上的数今天叫同一个名字，量的却不是同一件事：卡片上
是这次运行**至今的平均速率**（分母扣掉**暂停**），**采样**点上是**自上一个点以来那一段的吞吐**
（分母是墙上时间）。一条正被暂停的运行因此同时显示「300/min」与一条贴着零的曲线，而两个数都是对的。

两个数都保留，改的只是采样那一格的名字。
