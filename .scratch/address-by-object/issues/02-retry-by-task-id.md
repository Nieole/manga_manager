# 02 — 重试改按任务标识寻址

**What to build:** 用户点某条运行卡片上的重试，动到的一定是那张卡片对应的**任务**。今天重试按
**任务键**寻址并取「最近那一条」运行，而序号在入队与每次**合并**时都会重取——只要那个任务有一条
**排队中**的运行，它就永远是「最近那一条」，重试读到的是它而不是用户看着的那条刚失败的。

重试端点改为按任务的自增标识寻址（与禁用 / 启用端点同形），并明确读**最近一条进入终态的运行**
的**重启入参**：重试的意思是「那次跑完的，再跑一次」，排队中与运行中的都没有可重放的东西。

**Blocked by:** None — can start immediately
