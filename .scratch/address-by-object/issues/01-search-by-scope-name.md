# 01 — 关键词搜索改按作用域显示名匹配

**What to build:** 用户在任务中心的搜索框里打**资料库**或**系列**的名字，就能筛出它的**运行**与
任务清单里对应的那一行；今天只有打 `scan_library_1` 这种由身份四要素拼出来的内部串才命中。
打类型名（如 `scan_library`）仍然命中——那来自文案码，不受影响。

这张票同时是后面那张删列票的**前置整地**：它撤掉**任务键**那一列的一个读者。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 打资料库名字筛得到该库的运行（新用例）
- [ ] 打系列名字筛得到该系列的运行（新用例）
